Trade-offs I weigh

Indexes aren’t free

Every index speeds up reads and slows down writes. I index for the queries that actually run hot, not every column.

Column order matters

(user_id, created_at) serves “a user’s recent orders”. (created_at, user_id) mostly doesn’t. Equality first, then range.

Pessimistic vs optimistic

Row locks are simple when conflicts are common, like a hot wallet. A version column scales better when they’re rare.
